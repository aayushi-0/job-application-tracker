\# JobTrack



JobTrack is a full-stack job application tracker built with the MERN stack.



It helps users keep track of job applications, monitor application statuses, and view simple analytics from a central dashboard.



\## Features



\- Add, edit, and delete job applications

\- Track application status

\- Search applications by company or role

\- Filter applications by status

\- Dashboard with application statistics

\- Application pipeline overview

\- Application status distribution

\- Monthly application trends

\- MongoDB database for persistent storage

\- REST API built with Node.js and Express.js

\- React frontend with a responsive dashboard
